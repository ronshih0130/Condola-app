# B-026 — Vendor estimates and accounts

Scope: versioned pre-work estimates/photos, invited account settings/history, enhanced sharing approval and manager estimate/document comparison.

Out of scope: granting account/history access through a single-job token or exposing internal photos.

UI/copy: CAP-V-06/10/11, CAP-M-24 and brand-v2 vendor/manager patterns.

Data/migrations: propose `<unique_timestamp>_b026_vendor_account_estimates.sql` for missing account claims/versioned estimates; reuse existing sharing rules.

Acceptance:
- Given estimate submission, when above threshold, then B-013 approval starts and work remains blocked.
- Given invited account, when viewing history, then only assigned authorized jobs appear.
- Given token-only access, when requesting history, then it is denied.
- Given closed job, when enhanced link opens, then it is read-only and shows only approved shared photos.

Tests/evidence: claim replay, account/job separation, estimate revisions and sharing APIs under `/workspace/e2e/results/B-026/`.
