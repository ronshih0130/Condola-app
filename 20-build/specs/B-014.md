# B-014 — Owner ledger and report versions

Scope: net-ledger reconciliation, manually recorded company-to-owner transfers, report delivery events and immutable corrected versions.

Out of scope: actual remittance, inferred owner repayment or protected legal copy.

UI/copy: CAP-M-17/18, CAP-O-03 and brand-v2 owner report/PDF templates. Use approved “本期淨額為負”; deposits excluded.

Data/migrations: propose `<unique_timestamp>_b014_owner_transfer_report_versions.sql` if existing ledger/version metadata is insufficient.

Acceptance:
- Given opening balance, company-directed confirmed rent, expenses and transfers, when calculated, then closing balance reconciles.
- Given a reversal, when applied, then history is retained and totals reconcile.
- Given regenerated report, when saved, then old version remains and reason/actor/time identify the change.
- Given negative net, when rendered to screen/PDF, then neither implies repayment obligation.
