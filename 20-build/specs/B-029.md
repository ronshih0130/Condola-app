# B-029 — Usage events

Scope: event contract and hooks for units, signing including paper uploads, stored bytes, notifications and vendor jobs.

Out of scope: pricing, quotas or blocking core work when telemetry fails.

UI/copy: CAP-P-11/PLT-11; brand-v2 administrative table patterns if diagnostics are added.

Data/migrations: propose `<unique_timestamp>_b029_usage_events.sql`: org, dimension, quantity, time, source, dedupe key and sandbox marker with explicit grants/RLS.

Acceptance:
- Given each of five operations, when committed, then the documented event is recorded once.
- Given retry, when repeated, then usage is not double-counted.
- Given telemetry failure, when business operation completes, then business remains successful and diagnostic state is traceable.
- Given sandbox event, when summarized as formal usage, then it is excluded.
