## Invocation boundary for the producer

The new PARENT event is replacementIssued with fields ctx, exchange, owner, intentKey, url and api. The only supported API value is page.goto. The URL is the per-run HMAC for the exact raw explicit landing URL actually passed into that call. Emit once for the already-armed exchange and its actual owning context. Its ordinal must precede each terminal and the new Document's two independently observed request openings. closeIssued retains ctx and intentId and refers to the actual context.close call.

Capture invocation on entry to a source-locked actual method hook, or synchronously immediately after that method has returned its actual Promise and before awaiting it. A queued callback, future intention or general lifecycle flag cannot produce either event. A synchronous throw or rejected navigation/close must produce a sticky error. If a response or close callback is delivered reentrantly before an invocation can be journaled, the available evidence is insufficient. Do not reorder previously observed callbacks. The record proves invocation from the caller and subsequent measured event order. It gives no timestamp for internal browser dispatch or physical packet arrival. Only a separately reviewed producer can establish it calls this API with the recorded object and argument. The pure index recomputes the resulting provenance checks over the complete journal.

The HMR canonical source-anchor digest format, v2 read-start/capture windows, ExtraInfo ambiguity rules and observer-drain requirements remain as specified in v2-witness-contract.md. No additional signing or network component is introduced.
