# B018 browser egress guard v3

SOURCE DRAFT ONLY. No socket, network, browser, proxy, database or application was run. Frozen v2 is preserved. Independent QA of this source, the complete lifecycle reducer and parent orchestration is required, followed by a fresh lock and explicit authorization before any actual observation.

The guard retains v2's fixed local upstream, strict ordinary HTTP terminal accounting, private redacted-by-parent exchange witness, upstream-policy rejection, and failed/denied behavior. Every snapshot and close result is explicitly PROVISIONAL. A late error remains visible and fatal after close. The parent must retain both observer and append-only journal through natural observer-process exit, then independently reconcile the final journal hash, sequence and exit status with owned source/process lock and post-drain readback. Neither `close()` nor a forced exit seals a passing receipt.

The `wsModuleFile` must be the measured application's exact installed `next/dist/compiled/ws/index.js` SHA-256 `7b9865c26b0b6c148b4ed0d00dfc5409aff21e6a65851a2c5352b689f7351574`. The guard rejects resolution of optional native `bufferutil` or `utf-8-validate`; parent must separately pin actual dependency resolution and copy. Handshake requires exact local no-query HMR, HTTP/1.1, unique key/version/connection/upgrade headers, canonical 16-byte key, version 13 and matching SHA-1 accept. A compression offer is allowed; any negotiated extension or subprotocol is denied. It taps independent copied upgrade heads and subsequent bytes with two pinned Receiver instances using correct mask directions, splits bounded complete frames before passing them to the decoder, and rejects any extra bytes after close. Each direction is bounded to 1 MiB, 4,096 chunks, 8,192 frames and 120 seconds. Close statuses supported here are empty, 1000 and 1001; empty is represented as null, never an observed 1005/1006. Frame data, close reasons and raw bodies never enter the journal. Taps do not induce a peer close and then call it independent proof.

A trusted parent first joins the actual HMR exchange to one real document, calls `bindHmrOwner`, records an independent pre-action lifecycle intent, and calls `armHmrRetirement` before initiating navigation or close. `readLifecycleRecord` returns those already-recorded private lifecycle events; `commitHmrRetirement` checks a distinct source anchor identifying the document commit/context close/browser close and its hash. IDs are single use, unique across exchanges, and a mismatch is fatal. The guard does not independently observe CDP/PW document commits: the record callback is a trust boundary, and the final independently reviewed parent reducer MUST verify that the referenced anchor corresponds to the real event, correct owner, target and sequence. No caller-supplied identifier, callback or provisional guard event alone proves that anchor. Missing anchor, wire close, decoder terminal or independent socket close stays unavailable/fatal.

The in-memory tests use the actual installed Next Receiver and no network. They cover handshake, masked/unmasked directions, coalesced and split frames, normal fragmented messages, bilateral close, wrong mask/code, oversized frame, extra bytes, duplicate heads, independent peer closes while another context is live, invalid owner, unilateral EOF, old HTTP/cancellation and header findings, and a synthetic late error. Tests do not prove real Node stream scheduling, a browser's actual close behavior, exact callback-to-document correlation or a complete egress perimeter. Strict failures remain fatal even in a declared retirement.

V4 correction: ownership requires a successful private bind and an exact 64-hex owner-document digest. Matching null or unbound owner cannot arm/commit/settle. Upgrade peers propagate independently observed readable FIN using graceful writable.end only after genuine bilateral Close frames, preserving buffered writes and distinguishing forwarded FIN from independent wire-frame proof. No forced opposite destruction counts as clean retirement. Node in-memory half-open Duplex regression is provided; no socket was opened.
