# B018 browser transport guard proposal

Unreviewed source only. No proxy, browser, network or database has been run. This module does nothing on import. It is a concrete transport component, not runtime authorization or a substitute for independent actual controls.

`openBrowserEgressGuard({browserExecutablePath,browserExecutableSha256,onEvent})` opens an owned IPv4 loopback HTTP proxy only when invoked. The sole upstream is hard-coded `127.0.0.1:43156`. Absolute HTTP requests can target only that exact authority; CONNECT is denied, and WebSocket upgrades can target only that server's existing `/_next/webpack-hmr`. External/invalid redirect destinations are denied before forwarding them to the browser. No input URL selects the network destination. No URL, query, body, cookie, header, credential or session value is logged; `onEvent` receives only sequence/event/reason enums. Every denied attempt or transport error is fatal. It never follows redirects itself.

Launch the pinned browser with the exact `...guard.proxyLaunchOptions`, then `await guard.attach(browser)`. Attach checks the real browser CDP command line against the pinned executable path/stat, exactly one fixed proxy and forced loopback proxying, no direct/PAC/auto-proxy or extension override, and the explicit DNS-prefetch/QUIC/non-proxied-UDP launch arguments. These arguments are mitigations requiring independent compatibility review and actual controls; this source does not claim an operating-system firewall or proven arbitrary non-HTTP transport isolation. If the browser cannot establish the required launch or transport proof, execution remains unavailable.

`guard.assertBound(browser)` is synchronous. The collector must require the branded exact module handle and call `await guard.createContext({javaScriptEnabled,viewport})`, which blocks service workers and accepts no proxy override. The parent must forbid all alternate context/page factories, preserve every extra target/worker/unknown-transport event, and independently verify source/browser/process ownership. The actual browser binary, Playwright source, Node preload guard and this module must be in the immutable pre-run lock. The Node preload already permits upstream app port 43156; browser-to-proxy traffic is in the browser child, not the Node connector.

The collector owns per-context/page/CDP closure intentions, observer lifetime and complete failure accounting. After complete observations, call `guard.beginPlannedBrowserClose()` immediately before the normal awaited browser close; this marks the expected browser disconnect. Then drain the proxy with `await guard.close()`, preserving all prior failures and transport counts. Parent owns bounded timeouts, abnormal termination/quarantine and all process cleanup. A missing close/readback or previously failed guard can never grant bootstrap admission. No caller-supplied boolean or serialized object can replace the live branded handle.

This proposal needs highest independent source review, hostile local-only redirect/CONNECT/upgrade controls, actual browser proxy/bypass proof and independent post-drain checks before any integrated execution. Current kernel/map component source GO does not approve this guard or the corrected collector.
