# B018 native bootstrap policy kernel

Source for independent QA only. This directory contains a pure CommonJS module, normalized JSON evidence schema, tests and a local test report. It contains no browser collector, server, DB client, signing services, activation or runtime authorization. The governing policy is Ron's approved note, SHA-256 9e42d1bc0bb4a1080e8067dfd228b648022f97de559983d2e59cb02186580aec. The v2 classification proposal is not an implementation approval.

## Entry points

- qualifyNativeBootstrap(evidence, lock) returns nativeAdmission ADMIT or FAIL. Successful bootstrap returns aggregate PENDING. It requires no financial facts or final receipt.
- finalizeAggregate(evidence, postDrain, lock) recomputes native admission, every required financial case, the entire failure ledger and independent post-drain recovery. Only this function can return aggregate PASS. A future runtime supervisor must exit nonzero for any other final result. A qualified native failure always retains rawStrict FAIL. Missing/unverified evidence never returns raw PASS.
- digest(jsonValue) returns SHA-256 of recursively key-sorted compact JSON (UTF-8, safe integers only; array order matters). Producers must reject duplicate keys in source JSON, unknown/sensitive fields and malformed source artifacts. Terminal event IDs are globally unique, whereas PW and CDP request IDs have independent namespaces. The kernel does not read files, mutate inputs or create evidence.

## Parent trust and receipt timing

1. Freeze the approved note digest, fresh run, exact source/helper/browser, candidate, server generation and full finance-case list before observation. FINANCIAL_CASES is a mandatory minimum, not permission to skip existing financial/source/recovery checks. An exceptional webpack block requires a pre-frozen assetMapSha256. Lack of a stable map is permitted only for a clean path without exceptional native requests.
2. The frozen map must come from independently verified actual server resolution of the declared webpack path and permitted numeric renderer versions to identical compiled bytes. Capture after any necessary disposable dev compilation and before measured documents. A digest from an arbitrary supplied JSON map is not proof. No stable association means unavailable. Monitor generation and source/asset drift until final readback.
3. After bootstrap observations settle, the trusted parent snapshots all raw observer/error events and normalized evidence, durably, and issues a separate bootstrapReceipt. An API caller must obtain freeze and receipt from the trusted parent, never the observed page. Bootstrap receipt creation follows capture, not vice versa. Parent must account for every incoming event; do not mark capture complete after a crash or uncertain context. ObserverDrained here means the bootstrap observation cut is complete, not that all later browser processes/finance have finished. A live session reused later must have its entire bootstrap evidence flushed and no unresolved observations at that boundary. Later events still enter the final ledger.
4. Final receipt is a separate, later parent-owned digest of postDrain. Independent recovery verifies actual raw journals, DB/control and case receipts, all financial checks and source/ownership facts first. It then supplies final normalized fields. The kernel compares the final failure ledger with the bootstrap sequence and rejects extra/altered/dropped failures, missing cases, unknown drain or recovery failures. No six key/signing services are required. This is the locked local-parent plus independent readback trust boundary. Digests alone do not establish truth. Dynamic receipts never modify the original pre-run freeze.

## Producer evidence requirements

- Capture the real native and ordinary enabled click login for all three fixed actors, plus selected org, persona, consent, current server-backed session and expiry. Each actor uses distinct native and enabled contexts and distinct run-local session aliases. Native login and landing must form one main-frame document navigation chain in that context. A soft-navigation Fetch is not a landing Document. A separate natural authenticated document visit in the same enabled actor context can establish a counterpart but must preserve all actual enabled-login failures. Do not persist session UUID, cookie/hash, credentials, nonces or URL queries.
- failures is every observed bootstrap error, including ordinary enabled cancellations, HTTP/console/page errors, external attempts, unknown terminal, setup/teardown failure. allFailures is the same immutable bootstrap prefix plus all later failures. A complete eligible incident has exactly one matched PW failure and one CDP failure, with independent terminal event IDs. Correlate actual full URL/context/document/frame/loader/hop via a fresh run-secret keyed HMAC in memory; never persist that secret or raw URLs/queries. Missing/unmatched evidence is an error, not an empty ledger.
- Each document records all actual request hops and logical script/preload declarations for the sole reviewed webpack path, counted before filtering. A script tag plus a preload for precisely the same URL can be one logical declaration of kind both. Record exact decoded query classification: none, or a single renderer-proven decimal v. Any unsupported/repeated/unproven query is unavailable. Tokens within each document bind declaration, request and ledger. Across documents do not compare tokens for equality; use the independently pinned asset map and compiler-generation/content identity. No raw bytes may be imputed to a blocked response.
- For each measured render, entrySha256 is digest({run,context,document,frame,loader,fullUrlToken,queryKind,declarationSha256,mapSha256,compiledSha256}). Reconstruct each actual render mapping against frozen source. The map, enabled decoded response and attributed V8-covered script share one exact-byte digest. Bind V8 precise coverage to the actual script/document/context and digest (not merely scriptParsed/page ready). Count nonoverlapping executed bytes, >0 in the enabled context and exactly zero in a complete native capture. If a debugger/network representation cannot be reliably reconciled to the same bytes, no qualification.
- Initial v3 qualifies only positively observed zero enforced response CSP headers, report-only CSP headers and effective meta policies at request time on both actual documents. No nonce or integrity attribute, no uncertain policy. Nonzero or unknown remains unavailable even if a future parser might establish permission. This contract does not assert that real Condola documents have no policy.
- Keep every later enabled and financial error fatal, including canceled Fetch after 303 or with a finished sibling. Complete the existing financial workflow, protected data checks, exact OFF restoration and post-drain readback separately. Archived focus and login FAILs cannot be upgraded.

evidence-interface.json specifies the normalized fields. The pure tests include offline negative projections of frozen sanitized logs; they do not rerun any browser, database or application.
