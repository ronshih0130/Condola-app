## What the installed source establishes

Playwright’s pinned coreBundle.js:39027–39035 sets Chromium’s Emulation.setScriptExecutionDisabled when JavaScript is off. Bypassing CSP uses a different opt-in and was not requested. At :37756, Playwright uses CDP errorText, otherwise blockedReason, otherwise an empty value. A CSP block can therefore present a literal reason outside the helper’s error-code allowlist. That explains how such a reason can be redacted, not what the original six requests actually reported. No explicit CSP declaration was found in the checked app source/public configuration; next.config.ts:61 onward declares cache/referrer headers. This is not a measurement of effective response headers, meta policy, injected browser policy or Chromium internals.

The login form uses actionSignIn; src/server/auth-actions.ts:94–106 writes the session and redirects to the session entry. The entry and continue pages use Next redirects. Next 15.5.28 server-action-reducer.js:49–72 sends a POST fetch and reads an action-redirect header; :97–122 distinguishes Flight responses. Server action-handler.js:787–803 sets status 303 for a fetch action before generating its client-router redirect response. A 303 status is not itself an HTTP document navigation. action-handler.js:289–309 can cancel an unused non-Flight response body from an **internal server-side GET**. That is not evidence the two observed browser fetches were canceled by this branch. The client action POST at server-action-reducer.js:49–61 has no explicit AbortSignal. Client fetch-server-response.js:48–59,100ff wires a pagehide AbortController to router fetches. Lines 196–235 describe a conditional replay for redirected middleware/proxy RSC requests, expressly distinguished from server-action redirects. app-router.js:259–279 can initiate a hard navigation in another branch. No matched branch/initiator/pagehide signal was recorded for c14/c18. These paths supply hypotheses, not cause attribution.
