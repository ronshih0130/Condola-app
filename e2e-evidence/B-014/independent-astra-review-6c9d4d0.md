Bind both commands to the original rendered scope and compare it with the fresh canonical session before any mutation. Treat this as a precondition only. Exercise never-committed first submit/retry and reversal across a real cookie switch, as well as committed replay under the wrong actor. See `src/components/owner-transfers.tsx` lines 16–20, `src/server/owner-transfer-input.ts` lines 3–4, `src/server/owner-transfer-actions.ts` lines 6–7 and `src/server/owner-transfers.ts` lines 55–60, 67–72.
2. **P2. A stored JSON null silently discards the recovery guard.** `readJson` returns the same value when a key is absent and when it contains the literal four characters `null`. Both validators consequently treat malformed present storage as empty. The transfer form can issue a fresh UUID even when the previous outcome is unknown. Use a distinct sentinel for actual absence and reject a present non-object, including JSON null, for either key. Exercise both keys on a loaded page and verify no ledger, entry or audit writes. The existing browser test covers an invalid JSON string only. See `src/components/owner-transfers.tsx` lines 10–12, 17, 19–20.
3. **P2. A selectable owner and date can permanently freeze the ordinary record form.** The list includes historical and future assignments, while server admission requires that the assignment cover the supplied effective date. When the condition fails, the service returns ambiguous `unavailable` before any insert. The client retains the key, disables all editable inputs and repeats the impossible command after every refresh. Once exact prior replay and UUID collisions have been considered under the org lock and active authorization, distinguish this definitive rejection with a non-enumerating correction result. Preserve the pending key for genuinely ambiguous cases. Test an end-dated association or a date before the start and then a successful corrected submission in the same tab. See `src/server/owner-transfers.ts` lines 32–35, 44, 54–60 and `src/components/owner-transfers.tsx` lines 17–22.
