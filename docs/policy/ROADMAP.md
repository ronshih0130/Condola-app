# Condola 長期重點規劃（Ron 2026-10-27，依先後順序，以「週」為單位推進）

## P1 建立 ecosystem 四大應用
管理方、房客、屋主、Vendor 四個應用。完成後導入 design partner。

## P2 重設定價模式 + UX／design driven 打磨四大核心應用體驗
- 新定價模式（細節之後討論）：預計免費、不限戶數，以快速擴充用戶；提供基礎與進階功能，但依用量（by usage）設限，例如 org 存儲容量、電子簽約數量等。超過門檻就要升級付費方案，才能解鎖存儲和進階能力。
- 核心策略：大家都能來用，一來就能用進階功能；用一陣子超過門檻後開始付費。先擴大用戶、讓他們用全套，再轉化付費。
- 用 UX／design driven 的方式打磨四大應用的體驗。

## P3 擴展全球市場
- 建立 global 標準的通用能力、體驗與流程。
- 市場順序：台灣 → 美國 → 全球 → 東南亞。
- 可能在這個階段推出 Google／Apple App；SEO、marketing 也開始投入，擴展 organic growth。
