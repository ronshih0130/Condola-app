# Functions in schema public that authenticated may execute.
#
# One signature per line:
#   public.name(identity arguments)
# Identity arguments match pg_get_function_identity_arguments. Spaces are
# ignored. A line whose first character is # is a comment.
#
# "# @mode authenticated" — authenticated may execute the following
# signatures. anon must not. This is the only mode. "@mode any" is rejected
# by CI because the anon key is public and anon must execute nothing.
#
# src has no supabase.rpc(...) calls. The browser does not call PostgREST.
# anon can still call /rest/v1/rpc with the public anon key, so the gate
# does not depend on the key staying out of the client bundle.
#
# A function created after 20261030130000_default_function_privileges.sql is
# not executable by anon, authenticated, or PUBLIC. A client RPC needs both
# an explicit grant and a line in this file:
#
#   GRANT EXECUTE ON FUNCTION public.example(uuid) TO authenticated;
#
# CI (bash scripts/check-function-privileges.sh) applies every migration to a
# local database and queries has_function_privilege. anon executable count
# must be zero whether or not the default-privilege migration is in the tree.
# When 20261030100000_lock_public_function_execute.sql is present, every
# function authenticated can execute must be listed below.

# Called from invoker triggers while the session role is authenticated (and
# from service_role). Not PostgREST RPCs. None of these is SECURITY DEFINER.
# effective_rule and platform_max_id_retention_days stay because
# fn_lease_deposit_check, fn_allocation_rate_cap, and fn_org_retention_guard
# call them as the session user. condola_property_address_key stays because
# condola_set_property_address_key and condola_set_unit_import_address_key
# call it as the session user. It is IMMUTABLE, not SECURITY DEFINER, reads
# no tables, and has search_path = pg_catalog. condola_sync_unit_address_keys
# does not call it.
# @mode authenticated
public.effective_rule(p_jurisdiction uuid, p_org uuid, p_key text, p_on date)
public.platform_max_id_retention_days()
public.condola_property_address_key(display text)

# Called from tx() as authenticated. 20261021145000 revokes PUBLIC and anon.
# The lock migration keeps those grants and checks app.active_org_id.
# @mode authenticated
public.post_reversal(p_txn uuid, p_reason text)
public.fn_invoice_recalc(p_invoice uuid)

# Utility charge posting (PR #18) is on main at 2bedb89. The lock migration
# leaves authenticated EXECUTE and removes PUBLIC and anon. app.audit_event
# is in schema app, so the public function scan does not see it; the
# privilege script checks it directly when the function exists.
# @mode authenticated
public.post_reversal(p_txn uuid, p_reason text, p_invoice uuid)
app.audit_event(p_org uuid, p_event text, p_detail jsonb)

# Tenant signed-PDF RLS organization gate. Fixed-search-path SECURITY DEFINER;
# returns only whether the explicit organization feature flag is enabled.
# @mode authenticated
app.tenant_signed_pdf_on(p_org uuid)
